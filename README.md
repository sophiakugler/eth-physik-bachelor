# ETH Physics Bachelor

A collection of notes, exercise solutions, code, and other study materials from my **BSc Physics at ETH Zürich**.

I created this repository mainly to organise and archive material from my studies. Some of the solutions and notes are my own and may contain mistakes or incomplete sections.
More courses and materials may be added over time.

## About

The repository includes a mixture of:
- exercise solutions
- lecture notes and summaries
- Python / numerical work
- LaTeX files
- exam preparation material

This repository is **not affiliated with or officially endorsed by ETH Zürich**.

The material is provided primarily as a personal study archive. If you are currently taking one of these courses, please use the material as a reference rather than simply copying solutions.

Corrections and suggestions are welcome.
